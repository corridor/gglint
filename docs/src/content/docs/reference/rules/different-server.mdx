The same server is set up differently in two agents, so they don't behave the same. It's easy
to miss when you look at each file on its own.

```json
// .mcp.json (Claude Code)
"playwright": { "command": "npx", "args": ["-y", "@playwright/mcp@0.0.78", "--headless"] }

// .cursor/mcp.json
"playwright": { "command": "npx", "args": ["-y", "@playwright/mcp@latest"] }
```

```text
./.mcp.json:8:5  different-server `playwright` runs different versions of the npm package `@playwright/mcp`: 0.0.78 in Claude Code; the newest in Cursor
./.mcp.json:8:5  different-server `playwright` is started with different arguments: `--headless` in Claude Code; no arguments in Cursor
```

How you launch a package doesn't count as a difference: `npx -y pkg` and `bunx pkg` are the same,
and no version means `latest`.

## Fixing it

`uvx gglint mcp --fix` fixes different versions and different arguments by copying them from
the first agent that has the server, or from the one you name with `--source`:

```diff
# .cursor/mcp.json
-      "args": ["-y", "@playwright/mcp@latest"]
+      "args": ["-y", "@playwright/mcp@0.0.78", "--headless"]
```

It leaves environment variables, headers and on/off settings as they are. A different program or
URL, different environment variables or headers, or a server turned off in one agent might be
deliberate, so gglint only reports those. Look at `git diff` afterwards and fix the rest by hand.
