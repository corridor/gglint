title: missing-server
description: A server set up in one coding agent's MCP config file is missing from another agent's.
---

<RuleSpec command="gglint mcp" severity="problem · exit 1" fix="adds the server" />

A server is set up for one agent but not for another. Each agent only reads its own file, so
something that works in Claude Code quietly fails in Cursor, and whoever uses Cursor has no way
of knowing a server was supposed to be there.

```text
./.mcp.json:3:5  missing-server   `github` is set up for Claude Code but not for Cursor (.cursor/mcp.json)
```

## Fixing it

`uvx gglint mcp --fix` adds the server to every agent that's missing it, in that agent's format:

```diff
# .cursor/mcp.json
+    "github": {
+      "url": "https://api.githubcopilot.com/mcp/",
+      "headers": { "Authorization": "Bearer ${env:GITHUB_TOKEN}" }
+    }
```

If an agent really shouldn't have the server, take it out of the other agents as well. gglint
can see the files disagree, but not which one is right.
