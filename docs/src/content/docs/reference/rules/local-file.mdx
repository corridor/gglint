Some agent files are meant for one person's machine and should never be in git. They're where
secrets pile up without anyone deciding to write them down, so keeping the whole file out also
stops secrets that no pattern would catch. GitGuardian found about 31,000 secrets in
`.claude/settings.local.json` files on public GitHub
([report](https://blog.gitguardian.com/claude-code-settings-local-json-secrets-docker-hub/)).

It's a problem if the file is in git, and a warning if it's only on disk and git doesn't ignore
it yet. These are the files gglint looks for:

| File                                  | Agent         |
| ------------------------------------- | ------------- |
| `.claude/settings.local.json`         | Claude Code   |
| `CLAUDE.local.md`                     | Claude Code   |
| `.claude/.credentials.json`           | Claude Code   |
| `.codex/auth.json`                    | Codex         |
| `.continue/.env`                      | Continue      |
| `.github/copilot/settings.local.json` | Copilot CLI   |
| `.factory/settings.local.json`        | Factory Droid |
| `.gemini/.env`                        | Gemini CLI    |
| `.qoder/settings.local.json`          | Qoder         |
| `.qwen/.env`                          | Qwen Code     |

## Fixing it

`uvx gglint secrets --fix` adds the file to `.gitignore`. If it's already in git, also run:

```sh
git rm --cached .claude/settings.local.json
```

If you build container images from the repository, add it to `.dockerignore` too, and rotate
anything that was committed.
