The same server has a different name in different agents. Agents name tools after their server,
so a prompt or permission that mentions `docs` works in one agent and not in the one that calls
it `fetch`.

```json
// .mcp.json (Claude Code)
"docs": { "command": "uvx", "args": ["mcp-server-fetch"] }

// .cursor/mcp.json
"fetch": { "command": "uvx", "args": ["mcp-server-fetch"] }
```

```text
./.mcp.json:12:5  renamed-server   One server has different names: `docs` in Claude Code; `fetch` in Cursor
```

## Fixing it

Pick one name and rename the others by hand. gglint won't rename servers for you, because
something else might refer to the old name. It does know they're the same server, so `--fix`
won't add a second copy.
