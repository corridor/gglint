An agent has its own folder in the repository, like `.codex/`, but no MCP config file, so it
gets none of the servers the other agents have. This usually happens when someone adds an
agent for its rules or skills and never sets up its servers.

```text
./.mcp.json:3:5  missing-config   Codex has a .codex directory but no .codex/config.toml, so it gets none of the 4 MCP servers set up for Claude Code and Cursor
```

## Fixing it

`uvx gglint mcp --fix` creates the file with every server the other agents have:

```toml
# .codex/config.toml
[mcp_servers.github]
url = "https://api.githubcopilot.com/mcp/"
bearer_token_env_var = "GITHUB_TOKEN"
```

A `CLAUDE.md`, `AGENTS.md` or `.cursorrules` file on its own doesn't count as an agent being set
up, and neither do `.agents/`, `.github/` or `.gemini/` folders, since plenty of repositories have
those for other reasons.
