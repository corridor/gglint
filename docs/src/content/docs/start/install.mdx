title: Install
description: Run gglint with uvx or npx, or install it with npm, uv, pipx, pip or cargo. Linux, macOS and Windows.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Most people never install gglint. `uvx` and `npx` download it the first time and reuse it after
that. It's a single compiled program, so it doesn't need Python or Node to run, whichever one
you use to fetch it.

<Tabs syncKey="installer">
  <TabItem label="uvx">
    Needs [uv](https://docs.astral.sh/uv/getting-started/installation/).

    ```sh
    uvx gglint mcp
    uvx gglint@0.5.1 mcp   # a fixed version
    ```
  </TabItem>
  <TabItem label="npx">
    `pnpm dlx` and `bunx` work too.

    ```sh
    npx @gglint/cli mcp
    npx @gglint/cli@0.5.1 mcp   # a fixed version
    ```
  </TabItem>
  <TabItem label="npm project">
    ```sh
    npm install --save-dev @gglint/cli
    npx gglint mcp
    ```
  </TabItem>
  <TabItem label="uv / pipx / pip">
    ```sh
    uv tool install gglint   # or: pipx install gglint, pip install gglint
    gglint mcp
    ```
  </TabItem>
  <TabItem label="From source">
    Needs [Rust](https://rustup.rs) 1.88 or later.

    ```sh
    cargo install --git https://github.com/corridor/gglint
    ```
  </TabItem>
</Tabs>

On npm the package is called `@gglint/cli`, because npm wouldn't allow plain `gglint`, but the
command is still `gglint`. The rest of these docs write `uvx gglint`; swap in `npx @gglint/cli`
or just `gglint` depending on how you run it.
