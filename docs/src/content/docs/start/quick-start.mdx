title: Quick start
description: Run gglint's two checks on a repository and fix what they find, in about a minute.
---

import { Steps, Aside } from '@astrojs/starlight/components';

If you use more than one coding agent, each one is set up by its own files in your repository:
`.mcp.json` for Claude Code, `.codex/config.toml` for Codex, `.cursor/mcp.json` for Cursor, and
so on. Over time those files drift. You add an MCP server for one agent and forget the others,
or you approve a command in Claude Code and your database password gets saved in a settings file
that ends up in git.

gglint reads all of those files and tells you what's wrong. Right now it checks two things: that
every agent gets the same MCP servers, and that no secret is written into an agent's files. It
fixes most of what it finds, and it never deletes anything.

You don't need to install or configure anything. From the root of your repository:

<Steps>

1. **Check the MCP servers.**

   ```sh
   uvx gglint mcp
   ```

   ```text
     ╭────────────┬─────────────┬───────┬────────╮
     │ Server     │ Claude Code │ Codex │ Cursor │
     ├────────────┼─────────────┼───────┼────────┤
     │ github     │      ✓      │   ✗   │   ✗    │
     │ playwright │      ✓      │   ✗   │   ≠    │
     │ linear     │      ✗      │   ✗   │   ✓    │
     ╰────────────┴─────────────┴───────┴────────╯
     ✓ set up   ≠ set up differently   ✗ missing
   ```

2. **Check for secrets.**

   ```sh
   uvx gglint secrets
   ```

   ```text
   .cursor/mcp.json
     ✗  5:45  GitHub token in "Authorization" is written out in the file
   ```

   gglint shows where the secret is and what kind it is, never the secret itself.

3. **Fix what they found.**

   ```sh
   uvx gglint mcp --fix
   uvx gglint secrets --fix
   git diff
   ```

   Missing servers get copied over in each agent's own format, and secrets are swapped for
   environment variables. Look through the diff before you commit.

</Steps>

<Aside type="caution">
  If a secret was ever committed, it's still in git history. Rotate it.
</Aside>

No uv? Use `npx @gglint/cli` instead of `uvx gglint`, or see [Install](/gglint/start/install/)
for other ways to run it.

To find out more about what each check looks for, read [MCP servers](/gglint/checks/mcp-servers/)
and [Secrets](/gglint/checks/secrets/). To stop problems coming back, run gglint
[before every commit](/gglint/guides/pre-commit/) or
[on every pull request](/gglint/guides/github-action/).
