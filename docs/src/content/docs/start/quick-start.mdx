This page takes you from nothing to a repository whose agents get the same MCP servers and
whose agent files hold no secrets. It takes about a minute.

gglint runs with `uvx`, which comes with [uv](https://docs.astral.sh/uv/). If `uvx` isn't on
your machine, install uv with its
[installation guide](https://docs.astral.sh/uv/getting-started/installation/) first. For
other ways to install gglint, see [Install](/gglint/start/install/).

<Steps>

1. **Check the MCP servers.** From the root of a repository, run:

   ```sh
   uvx gglint mcp
   ```

   gglint draws each server in each agent as a table, then lists the problems:

   ```text
     ╭────────────┬─────────────┬───────┬────────┬──────────╮
     │ Server     │ Claude Code │ Codex │ Cursor │ OpenCode │
     ├────────────┼─────────────┼───────┼────────┼──────────┤
     │ github     │      ✓      │   ✗   │   ✗    │    ✗     │
     │ playwright │      ✓      │   ✗   │   ≠    │    ✗     │
     │ linear     │      ✗      │   ✗   │   ✓    │    ✗     │
     ╰────────────┴─────────────┴───────┴────────┴──────────╯
     ✓ set up   ≠ set up differently   ✗ missing   ○ turned off
   ```

   `uvx` downloads gglint the first time and reuses it afterwards; there's nothing else to
   install.

2. **Fix them.** Run it again with `--fix`:

   ```console
   $ uvx gglint mcp --fix
   Changed 4 files:
     .mcp.json                  added linear
     .codex/config.toml (new)   added github, playwright, linear
     .cursor/mcp.json           added github; updated playwright
     opencode.json (new)        added github, playwright, linear

   Review the changes with `git diff`.
   ```

   Each server is written in each agent's own format, and your comments and formatting are
   kept. `--fix` never removes a server.

3. **Review the changes.** Run `git diff`. A difference that was deliberate, such as a
   runtime chosen for one agent, shows up here. See [How fixing works](/gglint/concepts/fixing/).

4. **Check for secrets.**

   ```sh
   uvx gglint secrets
   ```

   ```text
   .cursor/mcp.json
     ✗  5:45  GitHub token in "Authorization" is written out in the file
               use ${env:GITHUB_TOKEN} and set GITHUB_TOKEN in your environment; rotate it,
               as it stays in git history once committed
   ```

   A secret's value is never printed: gglint shows its kind, the name it's under and where it
   is.

5. **Replace them.**

   ```sh
   uvx gglint secrets --fix
   ```

   Each secret it can replace becomes a reference to an environment variable, written in the
   agent's own syntax, and personal files such as `.claude/settings.local.json` are added to
   `.gitignore`. Set those variables in your environment.

   <Aside type="caution">
     A secret that was ever committed stays in git history. Rotate it.
   </Aside>

6. **Check every pull request.** Add this workflow as `.github/workflows/agent-secrets.yml`:

   ```yaml
   name: Agent secrets
   on:
     pull_request:
   permissions:
     contents: read
   jobs:
     gglint:
       name: gglint secrets
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v7
         - uses: corridor/gglint@v1
           with:
             command: secrets
             comment: "false"
   ```

</Steps>
